01 / Quick start

One endpoint

Configure your customer server as the API base URL. NexusBarcode sends the request to /api/barcode/generate. Keep your long-lived token on your own server whenever possible.

POST https://store-api.example.com/api/barcode/generate
Authorization: Bearer <your-server-token>
Content-Type: application/json

02 / Request

Send format and value

The request body is intentionally small. Your server should validate the format and value again before generating or saving anything.

{
  "format": "EAN13",
  "value": "400638133393"
}

03 / Response

Return a renderable result

Return one of svg, image_url, or png_base64. SVG is preferred for crisp previews and printing.

{
  "success": true,
  "format": "EAN-13",
  "value": "4006381333931",
  "svg": "<svg ...>...</svg>"
}

04 / Security

Protect the admin workflow

Use HTTPS, authenticate the operator, restrict CORS, redact credentials from logs, validate inputs server-side, and define a retention policy for barcode values and generated images.

The NexusBarcode browser module does not store barcode history or API secrets. In customer API mode, your server controls authentication, authorization, logs, and retention.
